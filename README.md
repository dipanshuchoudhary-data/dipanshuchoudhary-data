## Featured Projects

### [Quizzer](https://github.com/dipanshuchoudhary-data/Quizzer) — AI-Powered Secure Examination Platform

**Problem:** Traditional online exams are vulnerable to cheating, difficult to scale, and lack intelligent question generation.

**Solution:** A backend-authoritative examination platform with real-time integrity monitoring and AI-driven quiz generation designed for scalable academic assessments.

**Key Features:**
- Instructor-controlled AI quiz generation with configurable difficulty and topic scope
- Backend-authoritative exam flow that prevents client-side manipulation
- Real-time integrity monitoring with automated anomaly flagging
- Automated evaluation engine with detailed performance analytics

**Stack:** TypeScript · Node.js · LLM APIs · PostgreSQL

**Impact:** Enables secure, scalable academic assessments for institutions without the overhead of proprietary proctoring infrastructure.

---

### [Maantra-1.0](https://github.com/dipanshuchoudhary-data/Maantra-1.0) — Intelligent Slack AI Assistant

**Problem:** Teams lose productivity switching between tools, searching knowledge bases, and triggering workflows manually.

**Solution:** A production-grade Slack-native AI assistant with contextual memory, RAG retrieval, and real-world tool integrations — enabling intelligent automation directly inside team workflows.

**Key Features:**
- Persistent memory for context-aware, multi-turn conversations
- RAG pipeline for organizational knowledge retrieval with source grounding
- Tool integrations enabling real-world task execution from within Slack
- Workflow orchestration for automating repetitive knowledge work

**Stack:** Python · LangChain · LangGraph · Slack API · Vector DB

**Impact:** Reduces context-switching overhead and automates knowledge retrieval for engineering and operations teams.

### AI Essay Mentor — Intelligent Writing Feedback System *(Coming Soon)*

**Problem:** Students lack access to immediate, high-quality essay feedback, limiting the speed and depth of writing skill development.

**Solution:** An AI-powered mentor that evaluates essay structure, argumentation, and language quality — providing detailed, actionable, and personalized improvement guidance.

**Key Features:**
- Multi-dimensional scoring across structure, coherence, and argument quality
- Actionable feedback with specific, prioritized improvement suggestions
- Support for multiple essay types and academic levels
- Iterative improvement tracking across successive drafts

**Stack:** Python · LLM APIs · LangChain · Streamlit

**Impact:** Democratizes access to expert writing mentorship, enabling faster skill development for students at scale.
