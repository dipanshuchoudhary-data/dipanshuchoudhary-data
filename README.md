I build production AI systems where orchestration, reliability, and observability are first-class requirements. My current focus is agentic execution pipelines, RAG with strong retrieval discipline, and FastAPI backends that hold up in production. I optimize for systems that stay deterministic under pressure.

## What I Actually Build

| Area | What I Ship | Tech Behind It |
|---|---|---|
| Agentic AI systems | Multi-step execution flows with tool routing, persistent context windows, and explicit failure handling | Python, LangGraph-style orchestration, Redis, Docker |
| LLM systems | Structured generation pipelines with schema validation, retry policies, and policy guardrails | Python, Pydantic, FastAPI, OpenAI-compatible APIs |
| RAG pipelines | Retrieval stacks with chunking strategy, hybrid search, reranking, and citation-aware responses | PostgreSQL/pgvector, embeddings, retrieval evaluators |
| Backend services | API layers for inference, job control, and async workflow execution | FastAPI, Node.js, PostgreSQL, Redis |
| AI evaluation | Offline + online eval loops for grounding, hallucination rate, and response consistency | Python, custom evaluators, experiment tracking |
